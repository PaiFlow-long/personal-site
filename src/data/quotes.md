# 风中的纸屑 · 句子池
#
# ==================== 怎么加新句子 ====================
# 一行一句，直接往下贴就行，不用改任何代码。保存后重新部署即生效。
#
# 规则（都很宽松，写错了也不会报错）：
#   1. 一行一句。空行随意。
#   2. 行首的编号可以留着（1、/ 1. / 1) 都认），会自动剥掉。
#      所以从 Word 里整段复制过来也没问题。
#   3. 想带出处就在末尾写「——作者」，会自动拆成下面的小字署名。
#      例如：这是最好的时代，这是最坏的时代。——狄更斯《双城记》
#      署名写自己名字时用大写 Pai。不带出处的句子就只显示正文。
#   4. 想分类就在末尾加「 #成长」或「 #投资」（可选，目前全池混合抽取，
#      留着以后想按栏目过滤时用）。例如：……——芒格 #投资
#   5. 以 # 或 // 开头的行是注释，不会显示。
#
# ==================== 排版提醒 ====================
#   25 字以内 → 大字，一行放下（最好看）
#   26-60 字  → 中号，两到三行
#   60 字以上 → 小号，当段落排
# 字号是自动判断的，不用管。但同一句里别塞太长，超过 120 字会显得像正文。
#
