今天把个人站从零搭起来并上线了。记一下过程和几个关键决定，方便以后回看，也算是这个站的第一篇真实内容。

## 选型：为什么是网页 + Astro

一开始在"网页 / 小程序 / App"之间犹豫。对我来说，个人开发者、低维护是硬约束，所以排除了 App（双端商店 + 年费 + 审核）。最终选了**网页应用**，框架用 **Astro**——内容用 Markdown 文件驱动，改文字就是改文件、`git push` 自动上线，几乎不用养服务器。

## 架构：主站 + 子站

我想要一个主博客站放个人介绍和项目链接，再开独立子站放具体项目（比如 A 股研究站）。所以结构是：

- **主站（hub）**：个人介绍 + 各项目链接卡片
- **子站（spoke）**：每个具体项目一个独立站点，主站只放链接，不共享后端

Cloudflare Pages 免费层允许无限站点，开子站边际成本≈0，这套架构很合适。

## 踩坑：构建报错

第一次部署 Cloudflare 构建失败，报 `Cannot find module '@rollup/rollup-linux-x64-gnu'`。原因：我本地是 Windows，锁文件只记了 Windows 版工具，而 Cloudflare 构建环境是 Linux。

修复办法：**删掉 `package-lock.json`**（让云端改用 `npm install` 自动装对应平台依赖）+ 在 `package.json` 加 Linux 版 Rollup 可选依赖。重新 push 后部署成功。

## 一个诚实的边界

Cloudflare Pages 没有大陆节点，派友在国内晚高峰可能卡。所以它是**过渡站**——等以后走 ICP 备案 + 腾讯云做国内主入口，把同一个 `dist/` 传过去就行，代码一行不用改。
